🏛️ قصر الحلويات الفاخرة | Sweets Palace Platform
منصة تجارة إلكترونية تفاعلية، متكاملة، ومتجاوبة؛ صُممت لعرض عشرة أصناف فاخرة من الحلويات الشرقية والغربية بطابع رقمي فريد، يجمع بين البساطة البصرية والكفاءة البرمجية.
### 🎨 الهوية البصرية وخيارات التصميم
يرتكز التصميم العام للموقع على دراسة دقيقة لسيكولوجية الألوان وتفاعلها مع مشاعر الزوار وسلوكياتهم الشرائية، لضمان تجربة مستخدم متميزة.
| العنصر الهيكلي | رمز اللون (HEX) | الاستخدام الفني والهدف التصميمي في المنصة |
|---|---|---|
| الخلفية العامة | #FFF7F3 | توفير تباين بصري دافئ يبرز ألوان المنتجات الطبيعية بدقة ووضوح. |
| الأزرار والعناصر التفاعلية | #FF5F93 | لون متباين ومثير يحفز المستخدم على التفاعل الفوري مع الواجهات. |
| النصوص الرئيسية | #3B2F2F | بني شوكولاتي دافئ يحافظ على تباين لوني مريح ومتوافق مع المعايير الصحية. |
### 🛠️ التقنيات والميزات الهندسية المستخدمة
تم بناء المنصة بالكامل بالاعتماد على البرمجة الصافية (Vanilla Code) لضمان أداء استثنائي وسرعة تحميل فائقة:
 * **Semantic HTML5:** استخدام الوسوم الدلالية الموصى بها عالمياً؛ لضمان تحسين محركات البحث، وسهولة قراءة الواجهات عبر أدوات المساعدة.
 * **Fluid Layouts (CSS Grid & Flexbox):** تصميم متجاوب يعتمد على التوزيع التلقائي دون تداخل أو كسر في الهيكل العام للكتالوج الرقمي.
 * **JavaScript Interactivity:** تطوير شريط عرض ديناميكي، ومحرك مرن لفحص وتدقيق البيانات المدخلة في نماذج التواصل بلغة JS الصافية.
### 🚀 كيفية التشغيل والتحميل المحلي
يمكن تشغيل المشروع واستعراضه محلياً دون الحاجة لتثبيت برمجيات خادم معقدة، من خلال اتباع الخطوات البسيطة التالية:

### 📈 سجل عمليات الرفع والتطوير التدريجي (Git Commits)
تم تطوير المنصة بأسلوب متدرج، مع توثيق كافة المراحل عبر سجل منظم يعكس ممارسات العمل الاحترافية:
| رسالة الارتكاب البرمجي (Commit Message) | طبيعة التحديث وأثرها على بنية الواجهات |
|---|---|
| feat: initialize project | إنشاء البنية الأساسية، والمجلدات الفرعية، وتنظيم ملفات المشروع. |
| feat: build semantic HTML5 | بناء الهيكل الدلالي، وتدوين مواصفات المنتجات وصورها بدقة. |
| style: define global CSS | إدراج المتغيرات اللونية، وتفعيل أبعاد CSS Grid المتجاوبة. |
| feat: introduce dynamic slider | برمجة شريط الصور الترويجي، وتفعيل خواص التحكم بالتنقل. |
| feat: build robust validator | تفعيل محرك تدقيق المدخلات، والتحقق اللحظي لحماية البيانات. |
